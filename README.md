# Biblioteca Digital

Projeto simples de uma biblioteca digital feito com Spring Boot e Thymeleaf.

A aplicação apresenta uma tela inicial com opções para navegar por livros, autores, categorias, usuários e empréstimos.

## Como rodar

É necessário ter o Java 25 instalado.

No terminal, dentro da pasta do projeto, execute:

```bash
.\mvnw.cmd spring-boot:run
```

Depois, abra no navegador:

http://localhost:8081/livros

## Navegação

No menu da página, estão disponíveis:

- Livros
- Autores
- Categorias
- Usuários
- Empréstimos

Atualmente, as opções levam para a tela principal da biblioteca.
